1. Общие положения

Настоящая Политика определяет порядок обработки персональных данных пользователей сервиса — телеграм-бота @marina_docs_bot (далее — Сервис) и принимаемые меры по их защите.

Оператор исходит из принципа минимизации: обрабатываются только те сведения, без которых невозможно оказать услугу, и ровно столько времени, сколько это нужно.

2. Какие данные обрабатываются

  • идентификатор пользователя в мессенджере Telegram;
  • фамилия, имя, отчество — если пользователь указывает их при оформлении заказа, поскольку они должны войти в подготавливаемый документ;
  • адрес электронной почты — если пользователь указывает его при оплате;
  • сведения, самостоятельно сообщённые пользователем в заявке (описание задачи, сроки, пожелания и иные данные, которые он решил передать).

Оператор не запрашивает паспортные данные, СНИЛС, адрес места жительства, номер телефона, сведения о состоянии здоровья, а также иные специальные и биометрические категории персональных данных.

3. Зачем они обрабатываются

Единственная цель — оказание услуг по подготовке документов и выполнению заказов пользователей, то есть исполнение договора (публичной оферты), стороной которого является пользователь.

Данные не используются для рекламных рассылок и не передаются третьим лицам для продвижения товаров, работ и услуг.

4. На каком основании

  • пункт 5 части 1 статьи 6 Федерального закона № 152-ФЗ — обработка необходима для исполнения договора, стороной которого является субъект персональных данных;
  • согласие пользователя, выраженное при первом запуске Сервиса.

5. Сколько они хранятся

Сведения, переданные пользователем для выполнения заказа, **уничтожаются автоматически сразу после выдачи результата**. Это заложено в работу Сервиса, а не выполняется вручную.

После уничтожения сохраняются только номер заказа, наименование услуги, сумма и статус оплаты — они необходимы для налогового учёта и сверки с чеками. Персональных данных эти сведения не содержат.

6. Кому они передаются

Персональные данные третьим лицам не передаются и не распространяются.

Оплата проводится платёжным сервисом, который выступает самостоятельным оператором в части платёжных сведений. Трансграничная передача персональных данных Оператором не осуществляется.

7. Как они защищаются

Обработка ведётся в информационной системе, для которой в соответствии с постановлением Правительства РФ от 01.11.2012 № 1119 определён 4-й уровень защищённости персональных данных.

Применяются: ограничение доступа к рабочему месту, парольная защита, передача данных по каналам связи с использованием протокола TLS, резервное копирование, антивирусная защита. Доступ к данным имеет только Оператор.

8. Права пользователя

Пользователь вправе:

  • получить сведения об обработке своих персональных данных;
  • потребовать уточнения, блокирования или уничтожения данных, если они неполны, устарели, неточны или незаконно получены;
  • отозвать согласие на обработку.

Обращение направляется на 02042022@bk.ru. Ответ даётся в сроки, установленные Федеральным законом № 152-ФЗ.

Отзыв согласия до выполнения заказа означает невозможность его выполнить: без переданных сведений результат подготовить нельзя.
